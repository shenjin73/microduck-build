## 4. 决策点：HAT 打样 vs 模块拼装

| | A. 官方 Gerber 打样 | B. 模块拼装（推荐先走） |
|---|---|---|
| 内容 | [elec_RPI_Robot_HAT](https://github.com/pollen-robotics/elec_RPI_Robot_HAT) 直接送厂：4 层板 65×30.9mm、113 贴装位、必须 SMT | ¥22 半双工转接板（总线）+ UBEC（配电）+ ToF 直挂 i2c3 |
| 成本 | 数百元 + 起订量 | **~¥50** |
| 得到 | 板载音频（TLV320AIC3104 + PAM8406 功放 + MEMS 麦）、Qwiic 座、整洁 | 舵机总线 + 供电两件必需功能 |
| 失去 | — | **板载音频** → 过渡方案：MAX98357A I²S 功放模块（~¥5）+ 5W 小喇叭（~¥10）+ USB 麦克风（~¥20）先验证出声/录音 |
| 建议 | 鸭子走稳、要量产音频时再打 | **第一只鸭子走这条** |

## 6. 工具（没有才买）

万用表（必）、电烙铁+焊锡、热缩管/热熔胶、USB 键盘（已用显示器排障过一次）。

## 7. 明确不买

- ❌ Raspberry Pi 全系（生态不兼容，见 `zero3w-bringup-log.md` 选型）
- ❌ Orange Pi Zero 3 / Zero 3W（全志芯，命名陷阱）
- ❌ 瑞莎官方摄像头（¥130，通用 IMX219 ¥33 即可）、套餐里的 SD 卡/HDMI 线/电源
- ❌ NP-F970 电池、VL53L0X/L7CX、LM2596 降压
- ❌ 第二块 Zero 3W（备板等鸭子会走再说）
